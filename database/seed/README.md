# database/seed

Synthetic demo data, so the backend, frontend and demo do not depend on the 118k-row LOBSTER sample and
can show rejected records (the real sample has none).

    python database/seed/make_demo_seed.py       # builds data/sim/ through the real pipeline
    psql -f database/seed/load_seed.sql          # run from the project root
    psql -f database/schema/schema.sql           # rebuild tables, alerts and summary view
    psql -f database/checks.sql                  # all rows must be t

The seed is generated by `quality-service/src/lobster_sim.py` plus deliberate faults, so it is synthetic and
must be labelled as such in the report. Loading it replaces whatever is in `staging_messages`; run
`database/rebuild_database.ps1` afterwards to go back to the real sample.
